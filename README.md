# DataAnalystJobScanner

A lightweight search page for hybrid data analytics jobs in Chicago.

## Use

Open `index.html` in a browser. The default search covers data analyst, business
analyst, BI analyst, and analytics roles in Chicago, IL. Update the role keywords
or location as needed, then open a search on Google Jobs, Indeed, or LinkedIn.
Listings are retrieved by those job boards; this project does not scrape or store
job postings.
